# To-Do List

A small to-do list app: add, edit, complete, filter and delete. Built with React 19, TypeScript and Tailwind v4 on Vite, with no runtime dependencies beyond React itself.

Built step by step with Claude Code — the prompts, the plan-mode decisions and the review pass are written up in [DOCUMENTATION.md](DOCUMENTATION.md).

## Getting started

```bash
npm install
npm run dev
```

The dev server prints a local URL (http://localhost:5173 by default).

## Scripts

| Command           | What it does                                      |
| ----------------- | ------------------------------------------------- |
| `npm run dev`     | Vite dev server with HMR                          |
| `npm run build`   | Type-checks with `tsc -b`, then builds to `dist/` |
| `npm run lint`    | Runs Oxlint                                       |
